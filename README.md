# Отель Лермонтова - Система управления

Полнофункциональное веб-приложение для управления отелем: учет номеров, сотрудников, инвентаря и геймификация для персонала.

## Технологии
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL + Auth + Realtime)
- Lucide Icons

## Возможности
- **Номера**: статусы (свободен, занят, уборка, ремонт), типы, цены
- **Сотрудники**: роли, баллы, уровни, лидерборд
- **Инвентарь**: учет предметов, остатки, локации, предупреждения о низком запасе
- **Геймификация**: задания, баллы за выполнение, достижения, рейтинг сотрудников

## Настройка

### 1. Supabase
1. Создайте проект на [supabase.com](https://supabase.com)
2. В SQL Editor выполните скрипт из `sql/schema.sql`
3. Получите `Project URL` и `anon public key` в Settings > API
4. Скопируйте `.env.example` в `.env.local` и заполните ключи

### 2. Локальный запуск
```bash
npm install
npm run dev
```

### 3. Деплой на Vercel
1. Подключите репозиторий к Vercel
2. Добавьте Environment Variables: `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Deploy

## Схема базы данных
См. `sql/schema.sql`

## Демо-данные
После выполнения SQL будут созданы тестовые номера, сотрудники и инвентарь.
